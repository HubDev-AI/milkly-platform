# Milkly Platform

Monorepo for Milkly — an AI-powered newsletter platform.

## Workspaces

- `milkly-api` — backend API
- `milkly-app` — main web app
- `milkly-news` — public newsletter reader
- `milkly-shared` — shared code

See each workspace's own README for setup. Related repos: [milkly-ai](https://github.com/HubDev-AI/milkly-ai), [milkly-backend](https://github.com/HubDev-AI/milkly-backend), [milkly-webapp](https://github.com/HubDev-AI/milkly-webapp), [milkly-landing](https://github.com/HubDev-AI/milkly-landing).
